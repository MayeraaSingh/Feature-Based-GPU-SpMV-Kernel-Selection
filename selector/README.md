# Kernel Selector Module

**Owner:** Member 3 (Kernel selector, generalization evaluation, metrics, and calibration)

## Purpose

The `selector` module implements the predictive model that chooses an optimal GPU SpMV kernel for a given sparse matrix based on its extracted structural features.

## Planned Capabilities

- Feature preprocessing and scaling pipelines.
- Multi-class classification and ranking models (e.g., decision trees, random forests, gradient boosting).
- Selector inference interface accepting matrix features and predicting the best kernel.
- Fallback policies and uncertainty estimation.
