# Reproduction Guide

Exact commands, in order. Windows with an NVIDIA GPU is the reference platform (`docs/environment_setup.md`); steps marked
*CPU* also work without a GPU.

```bash
# 0. environment (CPU)
python -m pip install -r requirements.txt
python scripts/check_environment.py

# 1. dataset (CPU, network): crawl the NIST index, download and verify the selected matrices
python scripts/acquire_dataset.py crawl                      # data/metadata/mm_candidates.csv   (already committed)
python scripts/acquire_dataset.py refresh-missing            # only if some pages failed to parse
python scripts/acquire_dataset.py download --min-nnz 20000   # data/raw/matrix_market/*.mtx + dataset_manifest.csv
python scripts/acquire_dataset.py verify                     # SHA-256 of every file
python scripts/validate_dataset.py                           # load + CSR-validate every file

# 2. CSR pipeline: catalog, features, extended features, frozen split (CPU)
python scripts/run_pipeline.py --config configs/dataset_real.yaml

# 3. build and test the CUDA kernels (GPU)
python scripts/build_gpu.py
python -m pytest tests/test_gpu_correctness.py -q

# 4. benchmark (GPU, otherwise idle machine): two independent runs
python scripts/run_gpu_benchmark.py --out-dir results/run_real_001/benchmark
python scripts/run_gpu_benchmark.py --out-dir results/run_real_001_repeat/benchmark

# 5. selector training, one test pass, statistics, figures, report (CPU)
python scripts/run_experiment.py --run-id run_real_001
#    or everything including the benchmark:  python scripts/run_experiment.py --run-id <new_id> --benchmark

# 6. full test suite
python -m pytest tests -q
```

* Seeds: split 20261115 (`configs/dataset_real.yaml`), model and bootstrap seed 0 (`--seed`).
* A run id can evaluate its test split only once (`results/<run_id>/TEST_EVALUATED.json`). To repeat the analysis use a new
  run directory (copy `benchmark/` into it); the benchmark itself is deterministic only up to GPU timing noise.
* `results/<run_id>/run_manifest.json` records the git commit, input checksums, seeds and tolerance; `environment.json` the GPU,
  driver, CUDA and package versions.
* Figures and tables: regenerated by step 5 from the recorded CSVs; nothing is edited by hand.
* Timings depend on the machine; a different GPU gives different numbers and possibly different winners. The selection pipeline
  (steps 2 and 5) runs on any CPU given a `kernel_timings.csv` from a real benchmark.
