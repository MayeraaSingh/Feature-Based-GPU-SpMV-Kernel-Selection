# Scripts Module

**Owner:** Shared / Collaborative

## Purpose

This directory contains executable entry points and automation scripts supporting end-to-end tasks:
- `download_matrices.*`: Helper scripts to pull matrices specified in configs.
- `run_pipeline.*`: Pipeline driver to run validation, CPU reference, and feature extraction.
- `run_benchmarks.*`: Driver to run GPU benchmarks across all processed matrices.
- `train_selector.*`: Model training and cross-validation driver.
- `evaluate_generalization.*`: Evaluation driver to calculate generalization metrics and produce summary plots.
